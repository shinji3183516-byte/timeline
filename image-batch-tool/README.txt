画像一括整形ツール

【起動方法】
1. index.html をダブルクリックします。
2. Chrome、Edge、Safariなどのブラウザで開きます。
3. 画像をドラッグ＆ドロップします。

【主な機能】
・複数画像の一括リサイズ
・ファイル名の一括変更
・白色など単色背景の自動透過
・透明キャンバスへの下揃え、中央揃え
・PNG / JPG / WebP出力
・処理後画像の個別保存
・全画像をZIPで一括保存

【車画像の推奨設定】
・形式：PNG
・配置方法：比率維持・全体を収める
・水平方向：中央
・垂直方向：下揃え
・背景透過：ON
・透過しきい値：30～55程度から調整

【注意】
・画像処理はブラウザ内で行われ、外部へ送信されません。
・白い車、複雑な背景、半透明の窓や影は自動透過が完全でない場合があります。
・元画像は変更されません。
